# Aventura-Frutal-202205054-
Recoger frutas 

# Fase 1 Analisis 
En este trabajo se presenta el diseño y desarrollo inicial de “Aventura Frutal”, un videojuego sencillo en el que el jugador controla a un personaje que debe recoger frutas, obtener puntos y evitar obstáculos. El proyecto se encuentra en una etapa inicial y posteriormente puede incorporar nuevas funciones y niveles.El nombre representa la temática principal del videojuego, ya que el objetivo principal del jugador será recorrer diferentes escenarios para encontrar y recoger frutas.El objetivo principal de Aventura Frutal es conseguir la mayor cantidad de frutas posible mientras el jugador recorre un escenario lleno de obstáculos.
El jugador deberá utilizar diferentes movimientos para desplazarse por el escenario, recoger las frutas y evitar perder vidas.


# Fase 2 diagrama 
Para elaborar el diagrama de flujo de Aventura Frutal, primero identifiqué las principales funcionalidades y la secuencia de acciones que realizaría un jugador dentro del juego. Comencé definiendo el proceso de inicio, desde la descarga de la aplicación hasta la verificación de una partida guardada o la creación de una nueva.
Posteriormente, diseñé la estructura del menú principal, incorporando las opciones más importantes como jugar, acceder al inventario, modificar configuraciones, visitar la tienda, consultar logros y salir del juego. Después, desarrollé el flujo de juego, mostrando la progresión entre niveles, la recolección de frutas, la obtención de recompensas y las condiciones para ganar o perder la partida.
También añadí los sistemas complementarios, como el inventario, donde se almacenan frutas y objetos especiales, y la tienda, que permite utilizar monedas obtenidas durante el juego para desbloquear nuevas skins o personajes. Finalmente, representé las configuraciones personalizables, incluyendo sonido, música, vibración, idioma y nivel de dificultad.
Para facilitar la comprensión visual, utilicé diferentes colores en las flechas para distinguir las decisiones correctas, los errores y la continuidad del proceso, permitiendo identificar fácilmente cada ruta dentro del funcionamiento general del juego.
